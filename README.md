# Task 3 - SQL for Data Analysis

## Project Overview
This project demonstrates SQL-based data analysis using a sample e-commerce database and SQLite.

## Database Tables
- **customers:** Customer details and contact information.
- **products:** Product names, categories, and prices.
- **orders:** Order dates and order statuses.
- **order_items:** Products, quantities, and prices associated with orders.

## SQL Concepts Implemented
- SELECT, WHERE, ORDER BY
- GROUP BY, SUM, AVG
- INNER JOIN and LEFT JOIN
- Subqueries
- Revenue analysis
- Views for customer revenue
- NULL handling using COALESCE
- Index creation and query-plan analysis

## Tools Used
- Python
- SQLite
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run `python run_analysis.py`.
4. Review the SQL query results in the terminal.

## Files
- `task3_sql_analysis.sql` - SQL tables, sample data, and analysis queries.
- `run_analysis.py` - Executes the SQL script and displays results.
- `ecommerce_analysis.db` - Generated SQLite database.
- `screenshots/` - Screenshots of SQL query outputs.

## Conclusion
The project demonstrates how SQL can be used to retrieve, filter, join, aggregate, and analyze e-commerce data.
